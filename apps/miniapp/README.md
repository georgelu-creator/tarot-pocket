更新：2026-10-20。用户确认网页与小程序保留原有完整功能，两端名称统一为“秘境梦屿”，并同步资料、学习互动、日运版式和连续选牌优化。公开页面、简介和审核说明一致呈现真实服务，不以文化学习文案掩盖抽牌解读，不设置审核专属模式或审核后开关。

原学习键、当前牌局及当天日运恢复；历史文化版独立记录保持，不混用学习证据。保存失败不会覆盖已提交内容；原抽牌历史继续不保留。牌图仍由既有自有域名加载，首次需网络；未经微信真机测试，不宣称完整离线。

## 当前同版要求

牌库新增78张“画面→含义→原创生活例子”串联，补出22张近似牌比较；全文留在卡牌分包，不把寻物等牌阵分析写入通用单牌。课程保留短讲解和原练习，新增可选回忆／核对，不计分、不强制额外任务。日运结果对齐网页既有紫色刊头、日期、左右牌图与宜忌布局。

78张连续牌扇由原生scroll-view驱动，WXS在同一滚动回调更新可见牌；默认不显示序号，双指放大后显示。首次展开与前移在同一时间线重叠衔接，用户可立即接管，已有局不重播。连续动态采样、H5与原生工具、真实iPhone仍分别验证，不以截图宣称丝滑。
