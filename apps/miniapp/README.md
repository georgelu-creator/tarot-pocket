## 开发与验证

- `npm test`：78卡×三阶段、全部牌阵与正逆位、资料一致性及公开入口。
- `npm run type-check`：类型检查。
- `npm run build:mp-weixin`：微信编译、全量内容及分包检查；导入目录 `dist/build/mp-weixin`。
- `npm run test:ui`：H5四尺寸、完整仪式/存储故障/日运隔离、课程及78张资料，历史文化学习SFC单独兼容检查、预览安全。
