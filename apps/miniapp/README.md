# 星纱塔罗小程序工程（本地开发版）

更新：2026-10-12。uni-app Vue3 + TypeScript；与现有 Web 分开构建，复用原始中文内容和学习／本地解读引擎。保留现有 Web 独立工程；两端统一“塔罗日运”名称与先选牌阵、再填写可选问题的层级。本轮同步分阶段仪式、选牌确认、40个场景及逐牌位解读；取消抽牌历史并保留当前牌局与当天日运。

## 产品入口

首页优先推荐“开始抽牌”和“塔罗日运”，随后提供学牌和牌库。底部导航：首页、抽牌、学牌、牌库。学习方法融入课程；牌库独立查询完整牌义。新增逐牌深度资料：五领域正逆位、逆位分支、相近牌比较、情境例子与传统出处；课程每阶段只提取一个重点。

## 本地命令

在本目录执行 `npm ci --ignore-scripts`，再执行：

- `npm test`：共享内容、78张牌三个学习阶段、牌阵解读和入口回归。
- `npm run test:ui`：实际 H5 四种宽度、存储失败重试、日运封面和课程恢复（先在仓库根目录安装 Playwright 依赖及浏览器）。
- `npm run type-check`：类型检查。
- `npm run build:mp-weixin`：微信开发者工具导入 `dist/build/mp-weixin`。
- `npm run build:h5`：H5 编译。
- `npm run dev:h5`：编译后在 http://127.0.0.1:8877/ 预览；修改后重跑。仅提供构建产物，不开启旧版 Vite 源码/HMR 服务。

`prepare:content` 从仓库原始内容生成只读模块，产物不提交。完整深度资料仅进入 `pages/card` 分包，主包保留课程摘录；现有详情网址不变。`build:mp-weixin` 另检查真实输出的主包/分包边界和文件总量，不能代替微信工具认定的上传包体。运行端不使用 eval，也不依赖浏览器 window/DOM 执行共享引擎。内容仍适用原仓库 CC BY-SA 4.0；代码 MIT；历史牌图来源见根目录 assets/manifest.json。
