# 秘境梦屿 · 微信文化学习版

更新：2026-10-18。用户确认微信版转为经典卡牌图像、象征与故事的文化学习工具，名称为“秘境梦屿”；根目录网页版继续原有学牌、抽牌与解读功能。

## 公开体验

首页、学习、图鉴三个入口，独立图像详情页。学习一次只展示当前一幅图，按观察、认识象征、看图辨认推进；答错说明依据，答对后完成，安排到期回顾。完整78幅目录是二级入口，返回逐层退回并保留课程与目录位置。图鉴可搜索、分类、放大，详情保留真实历史来源。

发布代码只导入明确列出的图像字段。旧抽牌、日运、预测解读、牌阵、正逆位应用、AI和旧课程引擎不进入公开路由／编译包，也无远程开关或旧站功能链接。旧源码和兼容测试保留，不能从源码存在推断公开功能仍存在。

新版学习使用独立本地键 `mengyu-image-learning-v1`，不改旧学习和读牌记录。牌图仍由已有自有域名加载，首次需要网络，尚不宣称真机完整离线；不登录、不支付、不采集问题或行为，不调用AI。

## 开发与验证

在仓库根目录先准备依赖。然后在本目录执行：

- `npm test`：原共享内容／引擎兼容及新文化投影、入口检查。
- `npm run test:ui`：实际H5四种尺寸、文化学习／图鉴／详情、逐层返回、存储失败与旧数据保留、完整78幅资料。
- `npm run type-check`：类型检查。
- `npm run build:mp-weixin`：微信编译与真实包体／依赖边界检查，开发者工具导入 `dist/build/mp-weixin`。
- `npm run build:h5`：与微信同一文化体验的本地预览构建；不是根目录网页版。
- `npm run dev:h5`：编译后于 http://127.0.0.1:8877/ 预览，不提供源码或HMR服务。

`prepare:content` 从共享作者源生成完整旧兼容内容与独立的文化字段投影；只有后者被公开页面导入。资料包含真实图像出处，不能承诺平台一定接受这类文化学习内容。包体用文件字节和编译路由验证，微信工具认定的上传体积单独验收。

资料填写文本与功能边界见[微信资料](../../docs/MINIAPP_PROFILE.md)。AppID沿用已确认的现有账号；顶层DCloud appid仍为空。本轮浏览器策略阻止访问公众平台，后台名称、简介、类目、备案、认证和审核状态尚未核对／修改。
