# 1.9.0 中文学习与解读修复

状态：已合并并发布到正式域名；本地、CI、GitHub Pages、腾讯云服务器与固定虚构问题公网复测均有独立证据。真实 iPhone、微信 WebView、长期学习效果与长期模型质量仍需真人验证。

## 本版结果

- 公共产品只显示中文。旧 `lang=en` 链接和历史语言状态回落中文；页面没有英文切换入口，稳定 ID、三类本地存储和旧记录继续兼容。
- 首页与抽牌目录压缩无效留白，移动端首屏能看到主要任务；牌阵目录先显示用途短述，详情再显示完整用途、牌位和问题范围，并按牌数由少到多排列。
- 课程与 78 张牌库分开。现有 20 课按初级、中级、高级组织；每张牌先讲核心意思、画面线索和记忆方法，再练正位、整牌理解、逆位和间隔回访。完成正位、逆位与两次到期回访后才标记为已掌握。
- 学习模型共 98 个单元、724 题。381 条已审查错误选项均改为指出所选理解的问题并给出具体判断依据；错误反馈不得复制正确反馈，同一张牌两个整牌错误理解也必须分别纠正。
- 独立牌库包含全部 78 张牌、搜索和花色筛选；牌面详情补充核心牌义、正逆位、画面、数字或角色、场景示例、常见误读和近似牌区别，默认收起较长资料。
- 抽牌问题保持可选；未主动提问时按牌阵提供完整本地解读。预设问题与用户问题冲突会在洗牌前说明并让用户明确选择，不由系统暗中决定。
- 78 张牌在密集连续牌扇中全部可达，第一张完整显示；已选、揭牌与结果阶段都保持实际牌阵位置。补充问题后沿用原牌重新生成本地解读，旧 AI 回答保留在历史中。
- 离线解读先回答实际所问，再说明牌位、条件和行动；Yes/No 不以正逆位计票，二择一比较同一维度的两条路径，自由三张不擅自套成过去／现在／未来或其他固定角色。
- AI 只在用户点击“请 AI 深度解析”后建立临时会话并发送。服务端使用 RP-1.2.0，校验问题领域、牌阵范围与自由三张牌位；高风险问题直接给现实求助提示，不调用模型。
- 学牌页面没有播放、重播、看动效或跳过动效；洗牌、选牌入位和整组揭牌的必要反馈自动完成，并支持减少动态效果。

## 发布后旧入口修复

- 用户再次打开 `https://georgelu-creator.github.io/tarot-pocket/?lang=zh&v=1.7.3-…` 时看到旧邀请页。公网 HTML 已是 1.9；实际拦截者是浏览器里仍然控制 `/tarot-pocket/` 的 1.7.3 Service Worker，它会忽略导航 URL 的 `v` 参数并直接返回旧缓存首页。
- [PR #27](https://github.com/georgelu-creator/tarot-pocket/pull/27) 增加仅作用于旧 GitHub Pages 主机的迁移 Worker。它完成激活后再让旧页面重新导航，避免在 `activate.waitUntil()` 中等待 `WindowClient.navigate()` 造成新 Worker 永久停在 `activating`。
- 真实 Chromium 回归覆盖“安装旧 Worker—缓存旧首页—发布新 Worker—跳过等待—激活—重导航—跨域跳转”的完整链路；最终 URL 删除旧 `v`，保留其他查询参数和片段。正式域名原有离线生命周期和无关缓存不受影响。
- 强制迁移不删除旧来源 LocalStorage 或项目缓存。若旧来源仍有需要导出的记录，可用 `https://georgelu-creator.github.io/tarot-pocket/?legacy=export` 临时停留在旧来源完成 JSON 导出，再到正式域名导入。
