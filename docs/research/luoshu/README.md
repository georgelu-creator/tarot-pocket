## 最重要的结果

1. **不需要把牌库推倒重写。** 当前78张都有结构、核心、正逆位、五领域、近牌、例子及课程摘录；真正差别包含组织方式、解释取向和用户是否看得到。
2. **找到一个可证的展示覆盖问题。** 22张基础近牌比较已写，但详情只渲染另一层深度比较，没有完整合流。它与默认折叠的发现性问题分开记录。
3. **外部同作者覆盖尚不齐。** 核实10张专文（9全文、1摘录），另4张仅有抖音简介。68张缺少对应专文，其中4张有视频简介；不能说完成78张外部全文逐段对照。
4. **最适合借鉴的是生活场景和条件辨别。** 把图像→含义→案例→练习接起来，而非扩写所有领域或让初学者先背体系。
5. **寻物不是空白功能。** 当前已有生活分类失物三牌及离线/AI专属处理；应先改善说明、例子与发现性，不重复造入口。
