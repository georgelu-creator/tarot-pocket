# 2.0 学牌、牌库与解牌分离

2026-10-09。当前为发布候选；线上版本与验证记录在发布后补充。

## 实现

- 学牌以78张牌的连续进阶为主：认识画面与核心、正逆情境、整牌辨析和迁移；20个基础单元作为辅助。队列优先恢复未完成学习并穿插到期复习，错误反馈后使用已编写的变式，不要求自评或必填感悟。完成阶段与间隔回访分别记录。
- 牌库独立导航，78张牌按图像象征、正逆位长文、四领域、误读和近似牌区别查阅；不展示Yes/No、学习进度或抽牌角色。基本牌阵另列，保留版本、出处和真实位置。
- 新增圣三角、钻石、恋人金字塔、自我探索、吉普赛十字、六芒星、身心灵及无牌阵五张，共21种当前结构（含日运）、19种历史结构兼容。33个用途入口保持稳定ID。
- 日运完成后展示实际牌面、方向和提示，移除已完成牌的重复续接。扇形密集排列，结果保留竖向牌图，新增牌阵在目录、选牌、揭牌和结果使用同一位置配置。
- 本地解读使用牌义、方向和实际位置范围；期望与环境不会按现况解释。通用牌义背景与本位应用分开，不假装生成模型推理。AI仅在明确点击后调用，传入完整的所抽方向参考和实际问题对应领域，避免堆入无关领域。
- 后台增加功能点击、行为路径、最后观察节点及D1/D7/D30留存。用户问题仅在单独同意提交后进入反馈，最多30天、可从记录页撤回；一般统计不采集问题、牌面或学习答案。

## 审查与限制

高级模型预审发现的练习续接、反馈撤回入口、D30窗口、精确TTL及原生代理限流问题由中等模型修复，已分别运行定向验证。当前原生Caddy将真实来源传至回环API；Compose模式仍按代理共享反馈限额，未作为本次生产路线。

内容参考RWS公开原典和可核验牌阵资料后原创整理，没有整站复制现代网站文章。塔罗体系存在不同流派，本库采用并标注具体版本，不称唯一行业标准。课程使用有限、已编写的题与变式；不称无限动态题库，不以自动检查冒充记忆效果、独立教师审稿或真实iPhone验收。
