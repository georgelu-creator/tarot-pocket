# Tarot Pocket v1.0.0 · 塔罗随身学

Learn a card, remember why it means what it does, and continue without leaving the flow.

学会一张牌，记住它为什么这样解释，然后顺畅地继续下一张。

[Open on your phone / 手机打开](https://georgelu-creator.github.io/tarot-pocket/?lang=zh) · [English](https://georgelu-creator.github.io/tarot-pocket/?lang=en) · [Complete product plan / 完整产品方案](https://github.com/georgelu-creator/tarot-pocket/blob/main/docs/PRODUCT_PLAN.md)

- **78 complete first-learning flows.** Seven stages per card with a unique memory anchor, image evidence, close alternatives, quiet recall, comparison, contextual application and reversal practice. / **78 套完整初学流程。** 每牌七步，包含独立助记、图像依据、接近选项、静默回忆、辨析、情境应用与逆位。
- **Remember across visits.** Six independently recorded skills, SM-2 reviews, same-day retry protection, paused sessions and immediate next-card learning. Self-report is kept separate from exercise performance. / **跨次学习。** 六种能力独立记录、SM-2 复习、同日保护、中断续学和立即学下一张；自评与客观表现分开。
- **A calmer mobile experience.** Learn and Draw on the home screen; searchable cards, richer references, progress and foundational knowledge in the library. / **简洁手机体验。** 首页学牌与抽牌，牌库集中搜索、深入查阅、进度与基础知识。
- **Separate real readings.** Eight illustrated spread choices, optional local question, full-deck drawing and role-aware interpretations using the actual cards. No lesson quiz in a reading report. / **独立真实抽牌。** 八种牌阵图示、可选本地问题、完整牌组抽取和按实际牌位解读；解牌报告不混入教学题。
- **Offline preparation you can inspect.** Open the status panel and choose Download offline content. Wait for complete readiness, then reopen in airplane mode. Add to your home screen for repeat use. / **可检查的离线准备。** 打开状态面板下载离线内容，等待完整就绪后再用飞行模式重开；可添加到主屏幕。

## Files / 附件

`tarot-pocket-v1.0.0.html` contains the application, content, translations and all 78 verified historical card faces. `SHA256SUMS.txt` verifies that file. A standalone file's behavior on a phone's file viewer is not guaranteed; use the web app for the primary phone experience.

`tarot-pocket-v1.0.0.html` 内含应用、内容、翻译及 78 张已核验历史牌面，`SHA256SUMS.txt` 用于校验。手机文件预览器不一定支持单文件完整运行，手机主要使用上方网页。

## Compatibility and evidence / 兼容与验证边界

Existing three storage keys and JSON backups are retained. Export progress privately before moving browsers; Git does not transfer your learning or reading records.

保留三个旧存储键和 JSON 备份。更换浏览器前私下导出进度，Git 不迁移学习和抽牌记录。

Automated checks cover assets, bilingual content, learning, readings, compatibility, mobile layouts and offline web/file behavior. WebKit offline verification disconnects all application-origin requests; it is not physical iPhone testing. Independent teacher review, real iPhone restart/offline acceptance and long-term learning effectiveness remain unverified.

自动检查覆盖素材、双语内容、学习、抽牌、兼容性、手机宽度与网页／单文件离线。WebKit 通过断开全部本站请求验证，不等于 iPhone 实机。独立教师审核、真实 iPhone 重启离线及长期学习效果仍待验证。

Typed questions remain private local context; this version does not interpret arbitrary text with an AI service. Reports provide symbolic references and practical checks, not guaranteed real-world predictions.

输入问题仅作为本地私人背景；本版没有用 AI 服务解析任意文本。报告提供象征解读与现实核对，不保证现实预测。
