## English

The first public preview brings together the complete 78-card historical RWS deck,
English and Chinese learning content, and a tap-first practice and reading experience.

- A 12-step Four of Pentacles course: look, recall, distinguish, find evidence, and apply.
- Eight units with 56 steps and 24 additional mixed practice questions.
- Elements and numbers, three-card reasoning, reversals, and love/career/study contexts.
- Eight spread guides and a real 78-card draw with optional reversals, reveal animations,
  resumable tables, and up to 40 saved readings.
- Clear wrong-answer feedback, language switching, and private JSON progress backups.
- A single HTML file containing every image, lesson, script, style, source, and license notice.

Download **tarot-pocket-v0.3.0.html** below for the self-contained edition. **SHA256SUMS.txt**
contains its checksum. The source archives contain the complete project and original artwork;
follow the README to build and develop it. The hosted demo is not yet an installable PWA.

This is a product-experience preview. All cards have basic references; Four of Pentacles is
the complete deep-course sample. Review uses a disclosed 1-day/3-day demonstration rule.
iPhone offline acceptance and independent teacher/editorial review remain open.

Code is MIT; original learning content and documentation are CC BY-SA 4.0. Historical
artwork has separate source and public-domain notices. See the repository's license files.
