# v0.5.0 · Mobile learning and reading flow / 移动学习与抽牌流程

Tarot Pocket v0.5.0 turns the demo into two clear mobile paths: learn a card or
draw a spread for a real question. It keeps the existing deck, content, IDs,
storage keys, backup format, and build pipeline.

v0.5.0 把移动端 Demo 收成两条清楚路径：学习一张牌，或围绕真实问题抽一个牌阵。
既有牌组、内容、稳定 ID、存储键、备份格式与构建流程保持兼容。

## Changes / 变化

- Two-choice home and three-item navigation. / 首页只保留学牌、抽牌，底部导航收为三项。
- Learning-centered library with learned/due progress, New/Learned filters, richer
  card summaries, and explicit learned markers. / 牌库显示已学与待复习、未学与已学筛选、
  更丰富的卡片简介和主动学过标记。
- Elements and numbers live inside the library; existing advanced units remain in
  an optional collapsed section. / 四元素和数字进入牌库，原有能力练习收在可选折叠区。
- Eight visual spread thumbnails lead to scope, limits, positions, and reading order
  before the user enters a question. / 8 个牌阵先展示布局缩略图、能力范围、限制、牌位与读法，
  之后才输入问题。
- Real question input, optional wording context, full-deck shuffle, and a professional
  five-stage report separated from teaching. / 支持输入真实问题、选择措辞语境、完整牌组洗牌，
  并用五步专业报告解读，解牌不混入教学入口。
- Card practice completion now continues directly to another card. / 单牌练习结束后可直接进入下一张。

## Validation / 验证

`npm test` covers 78 verified historical card images, all 56 guided steps, 24 quick
questions, eight live spreads, English and Chinese, persistence and backup round trips,
offline Chromium use, accessibility behavior, and layouts at 320, 375, 390, 430, and
1280 pixels. Physical iPhone Safari remains to be tested by the user.

`npm test` 覆盖 78 张已核验历史牌图、56 个学习环节、24 道快练、8 个实际牌阵、中英文、
记录与备份往返、Chromium 离线使用、无障碍行为及 320、375、390、430、1280 像素宽度。
iPhone Safari 实机仍需要用户体验。
