# 2.0 产品重构实施框架

2026-10-09。状态：方案已实施，进入最终全量回归与发布验证。新版用户要求替代旧版三模块混用及简短参考输出，不以题量、字数或自动检查冒充教学效果。

## 为什么之前没有解决

上一版以页面可通、资料覆盖与自动检查作为主要验收，缺少用户任务验收：学习没有持续带领每张牌进阶；资料页混有课程进度及占卜判断；解读直接显示一句角色字段。响应式检查仅覆盖容器边界仍不能证明内部缩略图不遮文字。新验收必须覆盖真实页面内容、内部元素交叠和完整任务。

## 三个独立入口

- 学牌：默认继续系统安排的下一步。78张牌每张都包含认识画面与核心、正逆位情境应用、综合辨析与间隔提取；基础20课作为辅助知识。依据实际答题、提示使用和间隔决定复习；错题先解释依据，换情境再练，不做自评，不强制输入感悟。提供每牌阶段地图，允许自选但不要求用户自己规划顺序。已有记录保留，课程完成不等于长期掌握。
- 牌库：独立导航；78张单牌与基本牌阵两类资料。单牌包含核心、完整画面、象征、正逆位深解、感情/工作/学业/生活语境、常见误读与近似牌区别、出处。移除学习进度、开始课程、Yes/No及抽牌角色强加段落。牌阵资料包含真实名称、选用版本、完整图形、每个位置的问题、适用与限制和来源。资料与课程共用事实，但各自编排。
- 抽牌：基础牌阵保持原名和布局，按数量排序，包含Yes/No、自由三张与自由五张。日运抽完后入口展示当天的实际牌与短提示，避免与历史重复。揭牌默认本地详细解读：牌面含义、为何在该位置这样读、具体情境的表达、可留意的变化；无问题仍正常输出，不能编造用户经历。自由牌不暗加角色。可选AI主动确认后整组解析，明确利用完整牌义与牌阵结构。

## 内容与研究

采用RWS历史图与可核验公开原典，参考不同来源的组织方式后原创编写；不整站复制受版权保护的文章。不同牌阵流派保留版本出处，不声称唯一行业标准。用户截图只作为呈现和详尽程度参考，不视为已操作过小程序。课程采用有依据的提取、间隔、反馈策略（https://www.retrievalpractice.org/spacing ，https://www.retrievalpractice.org/feedback），不承诺固定几次必然记牢。

## 数据后台

保留第一方匿名事件、AI健康和管理鉴权，增加受控功能点击、页面路径、停留/退出、按首访日期的次日/7日留存。出口是观察到的最后节点，不冒充真实退出原因。留存只计算已完整经过窗口的群组；不能将未满7天的新用户算流失。原始问题反馈独立于常规埋点，默认不上传，用户明确勾选并提交后才保存，注明保留时间，并提供撤回；后台鉴权与转义所有文本。离线版不发送事件。

## 实施与发布验收

保留稳定卡牌ID、3种备份存储、旧牌阵历史及旧课程记录。分别做78张内容检查、学习全卡队列/变式/恢复检查、所有新增牌阵四阶段图形检查、手机视口内部遮挡检查、匿名统计/同意/鉴权/撤回检查。运行完整npm test。修复基线PR28曾失败的末牌选中浏览器问题。按用户要求使用高级模型独立审查，再由中等模型修正并运行相关检查；发布后核验版本、公开移动视口和管理鉴权。真实iPhone与长期教学效果单列未验证，不写成完成。
