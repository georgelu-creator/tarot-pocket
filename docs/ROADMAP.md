## Historical v1.0.0 capabilities · 历史能力（教学界面已由1.7替代）

- 78 seven-stage card courses with independent memory anchors, visual evidence, recall, comparisons and application. / 78 套七步课程，每张牌有独立助记、图像依据、回忆、辨析和应用。
- Per-skill SM-2 scheduling, same-day retry protection, resumable card sessions and continuous next-card learning. / 按能力点安排 SM-2 复习，限制同日晋级，支持中断续学与连续学下一张。
- A searchable library with learning records, rich dossiers, elements, numbers, court cards and major/minor references. / 可搜索牌库、学习记录、丰富资料，以及元素、数字、宫廷与大小阿尔克纳参考。
- Eight visual spread guides and separate full-deck readings with optional questions and role-aware interpretation. / 八种可视牌阵说明，独立的完整牌组抽牌，可选问题与按牌位解读。
- Bilingual installable web app, explicit verified offline download and a self-contained HTML backup. / 双语可安装网页，明确下载并校验离线内容，另保留单文件备份。

Implementation does not establish teaching effectiveness or physical-phone acceptance. The next work should improve evidence and specific learning gaps, rather than add more homepage modes.

功能实现不等于教学效果或实机验收。下一步应补齐使用证据和具体理解卡点，不继续堆叠首页模式。

## Improvements guided by evidence · 根据证据继续改善

Improve confusable-card questions when learners reveal real ambiguity. Broaden multi-card teaching paths and contextual variants after checking whether existing ones support transfer. New variants should require a different judgment, not just different wording.

根据真实混淆点修改近义题；检验已有训练能否迁移后，再丰富多牌教学与情境变式。新题应改变需要判断的内容，而不只是换措辞。

Evaluate FSRS or another scheduler only with an explicit data and migration plan. Legacy SM-2 records remain compatible. The academy uses observed answers and bounded follow-up intervals; retention effectiveness is not yet established.

评估 FSRS 等调度器之前，先明确数据与迁移方案。旧SM-2记录保留兼容，新学院按实际作答和有限回访规则运行，不能宣称学习效果已经证明。

Optional sync, accounts and native/App Store delivery remain separate product decisions after phone use is accepted. Git transfers source; private JSON backups transfer progress.

可选同步、账号、原生 App 和 App Store 仍需在手机体验认可后单独决策。Git 接力源码，私下的 JSON 备份迁移进度。

[Report a concrete issue / 反馈具体卡点](https://github.com/georgelu-creator/tarot-pocket/issues/new/choose): include the card or spread, confusing step and expected behavior; do not publish private questions or backups.
