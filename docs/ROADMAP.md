# Roadmap · 后续计划

[English README](../README.md) · [中文首页](../README.zh-CN.md)

The next release should help someone remember and interpret a card better. This roadmap orders product questions and completion criteria; it is not a fixed calendar or a promise that every idea will ship.

下一个版本应当让人更容易记住、理解一张牌。这份路线图按产品问题与验收条件排序，不是固定排期，也不代表每个想法都会上线。

## Available in the preview · 当前预览版

- 78 historical RWS images and basic bilingual card references. / 78 张历史 RWS 牌图与中英双语基础参考。
- 56 learning steps, 24 quick questions, and a complete Four of Pentacles sample lesson. / 56 个学习环节、24 道快练，以及星币四完整样本课。
- Eight spread guides and actual full-deck draws, with three question topics. / 八种牌阵指南、完整牌组实际抽取与三个问题主题。
- Explicit right/wrong feedback, separate interpretation/evidence checks, and ungraded quiet recall. / 明确判错、解释与依据分别检查、静默回忆独立自评。
- Local progress, resumable readings, and portable JSON backups. / 本地进度、抽牌续接与 JSON 备份迁移。
- A self-contained downloadable HTML edition. / 可下载、内容自包含的 HTML 版本。

## Next: make the experience trustworthy · 下一步：把体验验证扎实

| Work / 工作 | Completion evidence / 验收依据 |
| --- | --- |
| Learning-loop feedback / 学习过程反馈 | Learners can recall a mechanism without choices and explain one visual clue; collect concrete confusion points / 学习者能在不给选项时回忆机制、说明一个图像依据，并收集具体混淆点 |
| Bilingual editorial review / 双语审校 | Both languages preserve the same evidence, difficulty, feedback, and uncertainty / 两种语言的依据、难度、反馈与不确定性保持一致 |
| Tarot-teacher review / 塔罗教师审核 | Review sample lessons, close distractors, position logic, and stated traditions / 检查样本课程、接近干扰项、牌位逻辑与体系说明 |
| Phone and accessibility acceptance / 手机与无障碍验收 | Real-device reading, tapping, focus, reduced motion, backup, resume, and offline checks / 实机阅读、触控、焦点、减少动效、备份、续学与离线检查 |

## Then: broaden what can be learned · 之后：扩大能学会的内容

Expand complete single-card lessons in small reviewed groups, with visual evidence, recall, similar-card comparison, elements and numbers where appropriate, changing positions, and contextual application. Do not call a card “covered” simply because it has a reference paragraph.

按经过审核的小组扩展完整单牌课，包含图像依据、回忆、相似牌对照、适用的元素与数字、换牌位与情境应用。不能因为写了一段释义就宣称一张牌已经得到充分教学。

Add court-card role comparisons, more reversal mechanisms, same-number contrasts, and return questions with changed wording and context. Each addition should test transfer, not memorization of an option's location.

增加宫廷牌角色辨析、逆位机制、同数字对照和换措辞换情境的回访题，检验理解能否迁移，而不是记住选项位置。

Deepen spread learning from position questions to multi-card relationships and interpretation paths. Open readings should continue to distinguish what is visible, what is inferred, and what needs real-world information.

牌阵学习从牌位问题推进到多牌关系与解读路径。自由解读继续区分看见的事实、解释与需要现实补充的信息。

## Later decisions · 后续再决定的事项

- **Memory scheduling:** evaluate a mature scheduler against meaningful recall data, with understandable due dates and a gentle return after absence. The current 1/3-day rule remains a demo until replaced and validated. / **记忆调度：**以有效回忆数据评估成熟算法，说明复习时间，支持中断后轻松回归；当前 1/3 天规则仍是演示。
- **Installable offline experience:** choose delivery after actual iPhone tests; verify all assets, data retention, updates, and recovery. A cached page alone is not acceptance. / **可安装离线体验：**根据真实 iPhone 测试选择形式，核验素材、保存、升级和恢复，不能把一次缓存命中当作完成。
- **Optional sync:** consider only after local learning and export/import are dependable; specify privacy and conflict handling first. / **可选同步：**先把本地学习与备份做可靠，再明确隐私和冲突处理。
- **Native app / App Store:** decide after the user experience is accepted. No account, server, or native framework is required merely to continue the present demo. / **原生 App／App Store：**体验被认可后再决定，继续打磨当前 Demo 不以账号、服务端或原生框架为前提。

## Shape the priorities · 参与决定优先级

[Report a concrete issue](https://github.com/georgelu-creator/tarot-pocket/issues/new/choose) with the card, question, and point where the learning experience broke down. Contributions that make one lesson more understandable are as valuable as new features.

[反馈具体问题](https://github.com/georgelu-creator/tarot-pocket/issues/new/choose)时，请写清卡牌、问题和理解在哪一步卡住。让一堂课更易懂，与增加功能同样有价值。
